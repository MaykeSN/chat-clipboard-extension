Política de Privacidade — Chat Clipboard

Última atualização: 13 de maio de 2026

Resumo em uma frase: A extensão Chat Clipboard não coleta, não armazena, não transmite e não compartilha qualquer dado pessoal ou conteúdo de chat. Todo o processamento ocorre exclusivamente no seu navegador.

O que a extensão faz

A Chat Clipboard lê as mensagens visíveis na página do chat de atendimento (domínios *.invenit.cloud), formata o texto (limpando tags HTML literais e markdown do WhatsApp), e copia o resultado formatado para a área de transferência do seu sistema operacional, para que você possa colar em outro lugar (ticket de suporte, anotações, e-mail, etc.).

Dados acessados

  • Texto das mensagens visíveis na página de chat
  • Data e hora associadas a cada mensagem
  • URL da página atual (apenas para a extensão decidir se deve ou não rodar)

Nenhum outro dado é lido, inferido ou armazenado.

Para onde esses dados vão

  • Os dados permanecem exclusivamente no seu navegador durante o processamento.
  • Ao clicar em "Copiar chat", o texto formatado é copiado para a área de transferência local do seu computador.
  • Nenhum dado é enviado para servidores externos. A extensão não faz requisições HTTP/HTTPS/WebSocket para nenhum endpoint.
  • Nenhum dado é armazenado pela extensão. Não há histórico, banco de dados, cache persistente ou cookies.
  • Nenhuma telemetria, analytics ou métrica de uso é coletada.

Permissões utilizadas

  • clipboardWrite — necessária para gravar o texto formatado na área de transferência.
  • scripting — necessária para executar o código de extração em todos os frames da página, incluindo o iframe que contém o chat.
  • activeTab — necessária para acessar a aba ativa apenas quando o usuário aciona a extensão (clique no botão ou atalho de teclado).

Cookies e armazenamento

A extensão não utiliza cookies, localStorage, IndexedDB ou qualquer outro mecanismo de armazenamento persistente.

Compartilhamento com terceiros

Não há compartilhamento com terceiros. A extensão é completamente offline em termos de comunicação externa.

Alterações nesta política

Eventuais alterações serão publicadas nesta mesma página, com data de atualização atualizada no topo do documento.

Contato

Dúvidas, sugestões ou problemas? Abra uma issue no repositório GitHub do projeto.

Privacy Policy — Chat Clipboard (English)

Last updated: May 13, 2026

One-sentence summary: The Chat Clipboard extension does not collect, store, transmit, or share any personal data or chat content. All processing happens entirely within your browser.

What the extension does

Chat Clipboard reads the visible chat messages on the customer-support page (*.invenit.cloud domains), formats the text (stripping literal HTML tags and WhatsApp-style markdown), and copies the result to your operating system clipboard so you can paste it elsewhere (support ticket, notes, email, etc.).

Data accessed

  • Text of the chat messages visible on the page
  • Date and time associated with each message
  • URL of the current page (used only to decide whether the extension should run)

Where the data goes

  • Data stays exclusively in your browser during processing.
  • On clicking "Copiar chat" (Copy chat), the formatted text is written to your computer's local clipboard.
  • No data is sent to any external server. The extension makes no HTTP/HTTPS/WebSocket requests.
  • No data is stored. No history, database, persistent cache, or cookies.
  • No telemetry, analytics, or usage metrics are collected.

Permissions used

  • clipboardWrite — to write the formatted text to the clipboard.
  • scripting — to run the extraction code in all frames of the page, including the iframe that holds the chat.
  • activeTab — to access the active tab only when the user invokes the extension (button click or keyboard shortcut).

Cookies and storage

The extension does not use cookies, localStorage, IndexedDB, or any other persistent storage.

Third parties

No third parties are involved. The extension is fully offline in terms of external communication.

Changes to this policy

Any changes will be posted on this page, with the "Last updated" date at the top kept current.
